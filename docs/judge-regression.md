# AI 主持人判题回归（2026-09-17）

本轮根据用户提供的两张实测对照表校准主持人。**不改汤面与公开题目**；这是 prompt、私有裁判注释与复核流程的改动，不是大模型权重微调。

## 根因

1. 旧 prompt 先做相关性筛选，导致“我是人吗”这类题面已证实的普通事实被误判为“不相关”。
2. 旧规则把“没交代但不影响解谜”和“影响谜底却没交代”混为一谈，频繁返回“暂无法判断”。
3. “重要吗/有关吗”、口语省略和故事角色的“我”被过度解释为歧义或开放题；实际它们可以构成单一是非命题。
4. 旧服务只复核“部分正确/不相关”，不复核“无法判断/歧义”，错误拒答没有机会修正。
5. 两道故事部分事实边界缺少裁判注释：`silent-game` 的公司与当年拐卖链条是同一组织层面，不等于现任员工必是当年闯入者；`origin` 的时间是线索、不是超能力机制。

## 新顺序

1. 识别单一命题、角色指代、否定、因果和口语省略。真正开放题/多问/二选一才请改写。
2. 汤面、汤底或必然推论能确认的，回答是/否；单个因果解释只有部分成立才回答部分正确。
3. 未确认且真假都不影响谜底，回答不相关；影响谜底但资料不足，才返回不计次数的无法判断。
4. “无法判断/歧义/不相关/部分正确”的初判交由 Pro 独立复核；若复核给出明确结论，以复核结论修正。
5. 每题的语义边界和完整对照问句作为私有裁判资料传给模型，**不是**关键词硬编码。

16 条可完整读出的问句与 1 条根据被截断行补写的代表问法，在 `data/judge-calibration.mjs`；`tests/judge-calibration.mjs` 检查其未丢失、裁判资料正确送入模型、以及不确定初判触发 Pro 复核。截图中有两行问题被省略号截断，无法逐字建立原句断言；拿到完整文字后再增补。运行：`node tests/judge-calibration.mjs`、`node tests/integration-contract.mjs`、`node tests/vercel-adapter.mjs`。

这些本地自动化测试验证**接入与规则合同**，并不能代替真实 DeepSeek 输出的准确率测试。上线前还应使用实际生产密钥，在两道题的新会话中逐条跑完整问法与同义改写，记录 verdict、耗时、是否计轮次，并人工复核不确定样本。
